# InkyPi 取扱説明書

## はじめに

![InkyPi 本体](img/main_photo.png)

*InkyPi 卓上設置例*

InkyPi は電子ペーパーディスプレイです。朝は天気と予定、日中は写真と情報カード、夕方には明日の予定を自動表示します。電子ペーパーは表示保持時に電力を消費せず、目に優しいのが特長です。

同梱のスタンドで卓上に置いてお使いください。

## セットアップ

![設置例](img/setup.png)

*設置例*

1. 平らな場所にスタンドを置き、Wi-Fi の届く範囲に設置してください。
2. USB-C ケーブルを本体と電源アダプターに接続し、コンセントに差し込みます。
3. 電源を接続すると自動で起動します。
4. 約 30-60 秒で起動画面が表示され、以後自動でコンテンツが切り替わります。

初回起動時は設定に数分かかる場合があります。

## Webアプリの使い方

### アクセス方法

![ダッシュボード](img/dashboard.png)

*Webアプリ ダッシュボード*

スマートフォンまたはパソコンを同じ Wi-Fi に接続し、ブラウザで以下のアドレスを開きます。

```
http://inkypi.local/
```

IP アドレスが分かる場合は `http://192.168.xxx.xxx/` でもアクセスできます。

### ダッシュボード

アクセス直後に表示される画面です。現在のディスプレイ表示を確認でき、上部のナビゲーションから各機能ページに移動できます。

### 表示モードの切り替え

「モード選択」ページでディスプレイの表示モードを切り替えられます。

- **スケジュール**（標準）-- 時間帯に応じて自動切替
- **時計のみ** -- 大型時計表示
- **写真のみ** -- アップロード写真をスライドショー
- **カレンダー** -- 月/週/日表示

### 写真のアップロード

「写真」ページから画像をアップロードできます。写真モードにするとアップロードした写真が自動で表示されます。

<div style="page-break-before: always;"></div>

### 設定

![スケジュール編集](img/schedule.png)

*スケジュール編集画面*

「設定」ページでは以下の項目を変更できます。

- **デザインテーマ** -- 4種類の配色から選択
- **写真の切替間隔** -- 写真モードでの表示時間
- **カレンダー URL** -- Google カレンダー等の iCal URL
- **スケジュール編集** -- 各時間帯の表示内容をカスタマイズ

#### スケジュール編集

各時間帯（モード）ごとに以下を設定します。

- 名称、対象曜日、開始/終了時刻、表示時間（秒）、表示種別

「写真＋インフォメーションカード」を選ぶと、写真の合間に天気やカレンダー等の情報カードが約10分間表示されます。

## 全機能紹介

![プラグイン表示例](img/plugins.png)

*プラグイン表示例*

各機能はスケジュールに従って自動表示されます。

- **モーニングブリーフィング** -- 朝の挨拶、天気と予定、季節の写真
- **天気** -- 現在の気温、天気概況、湿度
- **時計** -- 4種のデザインから選択
- **カレンダー** -- 月/週/日表示
- **写真** -- アップロード写真または Unsplash の写真
- **ペインティング** -- 季節に合わせた名画
- **イブニングカード** -- 明日の天気と予定
- **グッドナイトカード** -- 月や星空の写真とメッセージ
- **ミール＆ボキャブラリー** -- 日葡の食事単語と料理写真
- **ムードカード** -- 季節の花写真と日英バイリンガルメッセージ
- **Wikipedia 今日の一枚** -- Wikipedia の注目画像
- **今年の進捗** -- 年の経過を視覚表示
- **関西イベント情報** -- 季節のスポットや催し
- **TODO リスト** -- 登録したタスク
- **カウントダウン** -- 記念日までの残り日数
- **RSS** -- 指定フィードの最新見出し
- **AI テキスト/画像**（OpenAI API 要）-- キーワードから生成
- **天文写真**（NASA API 要）-- 今日の天文写真
- **Unsplash**（Access Key 要）-- 高品質写真をランダム表示

![割り込み通知](img/interrupt.png)

*割り込み通知例*

予定の15分前または気象警報発表時に通知カードが自動表示されます。

## 写真の活用

### アップロード方法

1. Web アプリの「写真」ページを開く
2. アップロードボタンから画像を選択
3. 自動でアップロード完了

写真はぼかし背景付きで自動レイアウトされて表示されます。

### 表示設定

設定ページで以下を変更できます。

- 写真の切り替え間隔
- 画像の鮮やかさ、明るさ、シャープネス、コントラスト

## 便利な機能

### Google カレンダー連携

1. Google カレンダーの設定から「カレンダーの統合」の iCal URL をコピー
2. 設定ページの「カレンダーURL」に貼り付け
3. 保存

朝のブリーフィングやイブニングカードに予定が表示されます。予定の15分前には通知カードが自動表示されます。

### 天気設定

設定ページで緯度・経度を設定すると、その地域の天気が表示されます。気象警報が発表された場合は自動で通知カードが表示されます。

### API キー設定

| 機能 | 必要なキー | 取得先 |
|------|-----------|--------|
| AI テキスト/画像生成 | OpenAI API Key | platform.openai.com |
| Unsplash 写真 | Unsplash Access Key | unsplash.com/developers |
| NASA 天文写真 | NASA API Key | api.nasa.gov |
| 天気警報 | OpenWeatherMap API Key | openweathermap.org |

## 困ったときは

### 画面に何も表示されない

1. 電源ケーブルが接続されているか確認
2. 電源 LED が点灯しているか確認
3. 10分以上変わらない場合はケーブルを抜き30秒待って再接続

### 表示が更新されない

1. Wi-Fi に接続されているか確認
2. ルーターを再起動
3. Web アプリにアクセスできるか確認

### Web アプリにアクセスできない

1. 同じ Wi-Fi に接続されているか確認
2. URL が正しいか確認（`http://inkypi.local/`）
3. ルーターの管理画面から IP アドレスを確認し直接入力

### 時計や天気が正しくない

1. タイムゾーンが「東京/日本」になっているか確認
2. 天気の緯度・経度が正しいか確認

### カレンダーが反映されない

1. URL が正しいか確認（Google カレンダーの公開 iCal URL）
2. `webcal://` で始まる URL は自動変換されます
3. 設定後、最大5分程度かかることがあります
