## 1. はじめに — InkyPi とは

![InkyPi 全体写真](photo_placeholder_hero.jpg)

**InkyPi** は、あなたの毎日にそっと寄り添う「いま」を伝える電子ペーパーディスプレイです。

朝起きると、今日の天気と予定が優しく表示されています。
お昼には、美しい写真が静かに切り替わります。
夕方には、明日の予定とともにお疲れさまのメッセージが。

インクのようにくっきりと見えながら、電力ゼロで表示を保つ電子ペーパーだからこそ、
電源コードのない場所に置いたり、壁にかけたりと、自由にレイアウトをお楽しみいただけます。

> **Point**: 電子ペーパーは、印刷物のような質感が特徴です。画面を更新するときだけ電力を使用するので、とってもエコ。目にも優しいのが嬉しいポイントです。

## 4. セットアップ

セットアップはとっても簡単。電源を入れるだけです。

### 4-1. 置き場所を決める

![設置イメージ写真](photo_placeholder_setup_location.jpg)

- **おすすめの置き場所**
  - 玄関 — 出かける前に天気と予定をチェック
  - キッチン — 料理中に時計や写真を楽しむ
  - リビング — 家族みんなでスケジュール共有
  - 寝室 — 朝の優しい目覚めに
  - デスク — 作業中のおしゃれなインテリアとして

- 平らな場所に専用スタンドを置いてご使用ください
- 壁掛けの場合は、付属のマグネットプレートで簡単に取り付けられます
- Wi-Fi の届く場所に設置してください（初回セットアップ時に必要です）

### 4-2. 電源に接続する

![電源接続写真](photo_placeholder_power.jpg)

1. 付属のUSB-Cケーブルを本体背面のUSB-C端子に差し込みます
2. ケーブルのもう一方を電源アダプターに接続します
3. コンセントに差し込みます
4. 本体の電源ボタンを短く押します

### 4-3. 起動を確認する

![起動画面写真](photo_placeholder_startup.jpg)

電源を入れると、約30〜60秒で電子ペーパーに起動画面が表示されます。

その後、その時間帯に合わせたコンテンツが自動的に表示され始めます。

> **初回のみ**：初回起動時は自動的に設定が行われます。画面上に何も表示されない場合は、10分ほどお待ちください。

## 5. Webアプリの使い方

### 5-1. アクセス方法

![スマホで操作するイメージ](photo_placeholder_webapp.jpg)

パソコンやスマートフォンから、ブラウザで InkyPi にアクセスできます。

**アクセス手順：**

1. スマートフォンやパソコンをご自宅のWi-Fiに接続します
2. ブラウザを開き、アドレスバーに以下を入力します：

```
http://inkypi.local/
```

または、画面に表示されているIPアドレスを入力します：
```
http://192.168.xxx.xxx/
```

> **💡 ヒント**：iPhoneやiPadのSafariで「ホーム画面に追加」しておくと、アプリのようにすぐにアクセスできて便利です。

### 5-2. ホーム画面（ダッシュボード）

![ダッシュボード画面写真](photo_placeholder_dashboard.jpg)

アクセスすると最初に表示されるのがホーム画面です。

- **現在の表示** — 本体に表示されている内容がそのまま見られます
- **デモ再生ボタン** — すべての機能を順番にプレビュー
- **モード切替** — 「予定中心」「写真中心」「カレンダー」などにワンタップで切替

### 5-3. 表示モードを切り替える

![モード切替画面写真](photo_placeholder_mode_select.jpg)

**「モード選択」** ページでは、ディスプレイの表示モードを簡単に切り替えられます。

| モード | 説明 |
|--------|------|
| **スケジュールモード**（標準） | 時間帯に合わせて自動でコンテンツが切り替わります |
| **時計モード** | 大きな時計を表示し続けます |
| **写真モード** | アップロードした写真をスライドショー表示 |
| **カレンダー（月表示）** | ひと月の予定が見やすいカレンダー表示 |
| **カレンダー（週表示）** | 週単位の予定表示 |
| **カレンダー（日表示）** | 今日の予定を詳しく表示 |

> **💡 おすすめの使い方**：朝はスケジュールモード、お昼は写真モード、お出かけ前はカレンダーモード……と、シーンに合わせて切り替えてみてください。

### 5-4. 写真をアップロードする

![写真アップロード画面写真](photo_placeholder_photos.jpg)

**「写真」** ページから、お気に入りの写真をアップロードできます。

1. 「ファイルを選択」からスマートフォン内の写真を選ぶ
2. アップロードボタンをタップ
3. 写真モードに切り替えると、アップロードした写真がスライドショーで表示されます

> **Point**: 家族写真、旅行の思い出、ペットの写真、お気に入りのアート……なんでもOK。あなただけのフォトフレームになります。

### 5-5. 各機能の設定をカスタマイズする

![プラグイン設定画面写真](photo_placeholder_plugin_settings.jpg)

ホーム画面から各機能の設定画面にアクセスできます。

- **天気** — 表示する地域と単位を設定
- **カレンダー** — 共有したいカレンダーのURLを設定（Googleカレンダーなど）
- **予定表** — お気に入りのTODOリストを表示
- **RSS** — 気になるニュースやブログのRSSフィードを設定

> **💡 ヒント**：各機能の設定画面では、表示する項目のON/OFFや表示順序を細かくカスタマイズできます。

### 5-6. デザインテーマを変更する

![デザイン設定画面写真](photo_placeholder_design_settings.jpg)

「設定」ページから、全体のデザインテーマを変更できます（詳細は[7章](#7-デザインテーマを変える)をご参照ください）。

この他にも、画像の明るさ・鮮やかさの調整や、
画面の向き（縦／横）の変更なども行えます。

### 5-7. スケジュール設定

![スケジュール設定画面写真](photo_placeholder_schedule.jpg)

各時間帯に何を表示するかは、あらかじめ設定されたスケジュールに従います。
設定ページでは、このスケジュールを自由にカスタマイズできます。

```
朝 6:30 ─ 朝のひととき（天気＋予定）
  〜 7:30
朝 7:30 ─ 写真＋天気・カレンダーなど
  〜 8:15
朝 8:15 ─ 天気詳細
  〜 8:30
昼 12:00 ─ 今日の言葉と食事にまつわる表現
  〜 12:20
昼 12:20 ─ 写真＋インフォメーション
  〜 14:30
昼 14:30 ─ 今日の一枚（アート）
  〜 14:45
夕 18:00 ─ お疲れさまカード（明日の天気＋予定）
  〜 18:20
夜 21:00 ─ おやすみカード
  〜 21:10
```

各時間帯の長さや表示する内容は、お好みに合わせて変更いただけます。設定ページの「Scheduler」→「Time Slots」から、各時間帯の開始時刻・終了時刻・表示する内容・対象曜日を自由に編集できます。新しい時間帯の追加や不要な時間帯の削除も可能です。

### 5-8. APIキーの設定

一部の機能（AI画像生成やNASAの天文写真など）では、外部サービスのAPIキーが必要です。
**「APIキー」** ページから設定できます。

| 機能 | 必要なキー | 取得先 |
|------|-----------|--------|
| AIテキスト生成 | OpenAI API Key | platform.openai.com |
| AI画像生成 | OpenAI API Key | platform.openai.com |
| Unsplash写真 | Unsplash Access Key | unsplash.com/developers |
| NASA天文写真 | NASA API Key | api.nasa.gov |
| GitHub連携 | GitHub Token | github.com/settings/tokens |
| 天気アラート | OpenWeatherMap API Key | openweathermap.org |

> **Point**: APIキーは各サービスのサイトで無料で取得できるものがほとんどです。お手持ちのアカウントですぐにご利用いただけます。

## 7. デザインテーマを変える

InkyPi には4つのデザインテーマが用意されています。
設定ページからいつでも切り替えられます。

### 和（Wa）— クラシック

![和テーマ写真](photo_placeholder_theme_wa.jpg)

```
背景：あたたかみのあるベージュ
文字：落ち着いたダークブラウン
強調：上品なゴールド
書体：明朝体＋ゴシック体
```

伝統的な和のエレガンスを大切にしたデザイン。
書道のような明朝体の見出しが、上品な印象を与えます。

> こんな方に：和モダンなインテリアがお好きな方。木の温もりを感じるお部屋に。

### 禅（Zen）— ミニマル

![禅テーマ写真](photo_placeholder_theme_zen.jpg)

```
背景：清潔感のある白
文字：ソフトなグレー
強調：控えめなライトグレー
書体：ゴシック体（統一）
```

余白をたっぷりとった、クリーンで洗練されたデザイン。
情報が整理されて見やすいのが特徴です。

> こんな方に：シンプル・ミニマルなおしゃれがお好きな方。白を基調としたお部屋に。

### 力（Ryoku）— ボールド

![力テーマ写真](photo_placeholder_theme_ryoku.jpg)

```
背景：クリーム色
文字：しっかりとした黒
強調：鮮やかなレッド
書体：明朝体＋ゴシック体
```

コントラストの効いた、存在感のあるデザイン。
赤の差し色がポイントです。

> こんな方に：個性的で印象的なインテリアがお好きな方。アートな空間に。

### 今（Ima）— モダン

![今テーマ写真](photo_placeholder_theme_ima.jpg)

```
背景：クールなブルーグレー
文字：ネイビー
強調：ソフトなブルーグレー
書体：ゴシック体（統一）
```

都会的で洗練されたモダンデザイン。
クールトーンで統一された、スタイリッシュな印象です。

> こんな方に：モダンでスタイリッシュな空間がお好きな方。都会的な雰囲気のお部屋に。

### 季節の色との調和

デザインテーマは、選んだテーマのベースカラーに
**季節の色**がほんのりとブレンドされます。

- 春：桜色や若葉色がそっとプラス
- 夏：ひまわりや青空の色が映える
- 秋：紅葉の温かみのある色合いに
- 冬：雪や静けさを感じるクールな色合いに

> 季節の移り変わりを、ディスプレイの色合いでもお楽しみいただけます。

## 9. もっと便利に使う

### Googleカレンダーと連携する

![カレンダー連携写真](photo_placeholder_calendar.jpg)

GoogleカレンダーなどのiCal形式のカレンダーと連携できます。

**設定手順：**

1. Googleカレンダーを開く
2. 共有したいカレンダーの設定から「カレンダーの統合」をコピー
3. 設定ページの「カレンダーURL」に貼り付け
4. 保存するだけ

朝のブリーフィングや夕方のカードに、
自動的に今日・明日の予定が表示されるようになります。

### 天気情報を設定する

![天気設定写真](photo_placeholder_weather.jpg)

お住まいの地域の天気情報を表示するには、設定ページで
「緯度」と「経度」を設定してください（おおよその住所で結構です）。

> 天気情報は自動で取得されるので、設定はこれだけ。雨の日には傘マークも表示されます。

### 旅行前にチェック！関西のイベント情報

![関西イベント写真](photo_placeholder_kansai.jpg)

関西地方（兵庫・大阪・京都・奈良・滋賀・和歌山）の
季節のイベントや見どころを表示します。

- 春の桜スポット情報
- 夏祭りや花火大会
- 紅葉の名所情報
- 季節の特別拝観・催し

> お出かけや旅行の計画にぴったり。地元の新しい発見があるかもしれません。

### RSSフィードで大好きな情報を

![RSS写真](photo_placeholder_rss.jpg)

気になるブログやニュースサイトのRSSフィードを設定すると、
最新の記事の見出しが表示されます。

> お気に入りのライフスタイルブログ、地域のニュースサイト……あなたの情報源をディスプレイに。

### AIでテキストや画像を生成する

![AI生成写真](photo_placeholder_ai.jpg)

## 10. 困ったときは

### 画面に何も表示されない

| 確認項目 | 対処法 |
|---------|--------|
| 電源ケーブルは差さっていますか？ | コンセントと本体の両方を確認してください |
| 電源LEDは光っていますか？ | 消灯している場合は電源ボタンを押してみてください |
| 10分以上経っても変わらない | 電源ボタンを長押し（5秒）して再起動 |
| それでも表示されない | 電源ケーブルを抜き、30秒待ってから再度接続 |

### 表示が更新されない

| 確認項目 | 対処法 |
|---------|--------|
| Wi-Fiは繋がっていますか？ | 本体はWi-Fi経由で情報を取得しています |
| ルーターの再起動 | ルーターの電源を入れ直してみてください |
| Webアプリにアクセスできるか確認 | `http://inkypi.local/` にアクセス |

※ 電子ペーパーは電源を切っても表示を保持しますが、更新するには本体の電源が入っている必要があります。

### Webアプリにアクセスできない

| 確認項目 | 対処法 |
|---------|--------|
| 同じWi-Fiに接続していますか？ | スマートフォンやパソコンが、本体と同じWi-Fiに接続されているか確認してください |
| `inkypi.local` でアクセスできない | `http://inkypi.local/` と正しく入力しているか確認 |
| IPアドレスで試す | お使いのルーターの管理画面から本体のIPアドレスを確認し、直接入力 |

### 時計や天気が正しく表示されない

| 確認項目 | 対処法 |
|---------|--------|
| タイムゾーンは正しいですか？ | 設定ページで「東京/日本」が選択されているか確認 |
| 天気の地域は設定しましたか？ | 設定ページで緯度・経度を確認 |

### カレンダーが反映されない

| 確認項目 | 対処法 |
|---------|--------|
| カレンダーURLは正しいですか？ | Googleカレンダーの「公開URL」であることを確認 |
| URLの形式 | `webcal://...` で始まるURLは自動で変換されます |
| 反映まで時間がかかる | 設定後、最大5分ほどお待ちください |

### 本体が熱くなる / 動作が不安定

- 風通しの良い場所に設置してください
- 直射日光の当たる場所は避けてください
- ホコリの多い場所は避けてください
