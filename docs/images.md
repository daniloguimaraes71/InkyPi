# Image Preparation Guide

Place all images in `docs/img/`. Each image should be cropped and resized before placing.

## Required images

| File | Content | Orientation | Size | Notes |
|------|---------|-------------|------|-------|
| `hero.jpg` | InkyPi on stand in a room setting (living room, desk, or kitchen). Show the device displaying content. | Landscape | 800 x 480 or wider | Main product shot. Device should be active. |
| `contents.jpg` | All box contents laid out flat: device, cable, adapter, stand, card, manual. | Landscape | ~1200 x 800 | Clean background (white or wood). Items arranged neatly. |
| `parts.jpg` | Close-up of device front, with labels overlaid: screen, LED, power button, USB port. | Portrait | ~600 x 800 | Ideally use the actual product photo with numbered callouts added in editing. |
| `setup.jpg` | Device on stand with USB cable plugged in, on a desk or table. | Landscape | 800 x 480 or wider | Show the device powered on. |
| `dashboard.jpg` | Web app dashboard as seen on a smartphone browser. Show the main screen with clock, status, and schedule list. | Portrait | ~400 x 800 | Screenshot from iPhone or Android. Clean browser chrome. |
| `schedule.jpg` | Settings page with the Daily Schedule section visible, showing the time slot editor. | Portrait | ~400 x 800 | Screenshot with the schedule editor expanded and at least one mode row visible. |
| `plugins.jpg` | One example plugin card displayed on the InkyPi screen. Preferably the Morning Briefing card showing weather + calendar events. | Landscape | 800 x 480 | Take a photo of the actual e-paper display showing a real card. Good lighting, no glare. |
| `interrupt.jpg` | Calendar notification or weather alert card on the e-paper display. | Landscape | 800 x 480 | Same as above but showing an interrupt card. |

## Optional enhancements

- `theme_wa.jpg`, `theme_zen.jpg`, `theme_ryoku.jpg`, `theme_ima.jpg` -- Four small theme comparison photos if space permits in a revised layout.

## Post-processing

1. Crop each image to remove unnecessary background.
2. Resize to the recommended dimensions (larger is fine; PDF engine will scale down).
3. JPEG quality 85% is sufficient for print.
4. For callouts on `parts.jpg`, use image editing software to add numbered circles (1-5).
5. For screenshots: use a phone emulator or real device with the web app open. Set the theme to "Wa" for consistency.
