# InkyPi Kansai Companion — Project Context

## Overview
This is a fork of InkyPi (github.com/fatihak/InkyPi) customized into a
lifestyle companion for a Japanese woman in her 30s living in the Kansai region.

## Core Philosophy
- Photo frame / watch screen is the resting state (80%+ of the day)
- Information cards appear briefly at strategic times, then disappear
- Japanese aesthetic: 余白 (whitespace), 季節感 (seasonal awareness), 手帳感覚 (planner feel)
- E-ink's matte quality is a feature, not a limitation

## Tech Stack
- Python 3 (Flask web UI)
- Pillow for image composition
- Waveshare e-ink display drivers
- APScheduler for timed card rotation
- Google Calendar API / CalDAV for calendar integration
- Weather API for forecasts and alerts
- Public domain art APIs (Rijksmuseum, Met, Wikimedia)

## Features (planned)
1. Resting State: Photo frame mode + Watch/clock mode (user configurable)
2. Morning Briefing Card (06:30, 60 min)
3. Weather Card (08:15, 15 min)
4. Meal + Portuguese Vocabulary Card (12:00, 20 min)
5. One Painting / Art Card (14:30, 15 min) — season/weather matched
6. Coffee Break Card (16:00, 10 min) — mood card with seasonal image
7. Evening Card (18:00, 20 min)
8. Good Night Card (21:00, 10 min)
9. Calendar notification interrupts (priority-based)
10. Weather alerts / rain reminders
11. Japanese micro-season (二十四節気 + 七十二候) woven into all screens
12. Weekend Kansai events discovery
13. Smart home dashboard (expandable, works without devices)
14. Weekly Portuguese review (Sunday)
15. Family photo management with smart selection

## Design Language
- All cards share same visual DNA: focused content + micro-season in corner
- Typography: Noto Serif JP for display, Noto Sans JP for body
- Seasonal color palettes that shift every ~2 weeks with micro-seasons
- 7-color e-ink: use palette gently — muted reds, soft greens, warm yellows
- Photos take 80%+ of screen time. Cards are brief guests.
