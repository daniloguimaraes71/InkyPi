1. はじめに

InkyPi は電子ペーパーディスプレイです。朝は天気と予定、日中是央には写真と情報カード、夕方には明日の予定を自動表示します。電子ペーパーは表示保持時に電力を消費せず、目に優しいのが特長です。

同梱のスタンドで卓上に置くほか、マグネットプレートで壁掛けも可能です。

3. 各部の名称

  1. 電子ペーパー画面 – 表示部（800 x 480）
  2. 電源 LED – 緑点灯：ON / 消灯：OFF
  3. 電源ボタン – 短押しで起動/終了
  4. USB-C 端子 – 電源接続
  5. microSD スロット（背面）

4. セットアップ

  1. 平らな場所にスタンドを置き、Wi-Fi の届く範囲に設置
  2. USB-C ケーブルを本体と電源アダプターに接続、コンセントに差し込む
  3. 電源ボタンを短押し
  4. 約 30-60 秒で起動画面が表示され、以後自動でコンテンツが切り替わる

初回起動時は設定に数分かかる場合があります。

5. Webアプリの使い方

5-1. アクセス方法

スマートフォンまたはパソコンを同じ Wi-Fi に接続し、ブラウザで以下のアドレスを開きます。

http://inkypi.local/

IP アドレスが分かる場合は http://192.168.xxx.xxx/ でもアクセスできます。iPhone/iPad の Safari では「ホーム画面に追加」するとアプリのように使えます。

5-2. ダッシュボード

アクセス直後に表示される画面です。現在のディスプレイ表示を確認でき、上部のナビゲーションから各機能ページに移動できます。画面は定期的に自動更新されます。

5-3. 表示モードの切り替え

「モード選択」ページでディスプレイの表示モードを切り替えられます。

  • スケジュール（標準）– 時間帯に応じて自動で内容切替
  • 時計のみ – 大型時計表示
  • 写真のみ – アップロードした写真をスライドショー
  • カレンダー – 月/週/日表示から選択

5-4. 写真のアップロード

「写真」ページから画像をアップロードできます。写真モードにするとアップロードした写真が自動で表示されます。スマートフォンから直接アップロード可能です。

5-5. 設定

「設定」ページでは以下の項目を変更できます。

  • デザインテーマ – 4種類の配色から選択
  • 写真の切替間隔 – 写真モードでの表示時間
  • カレンダー URL – Google カレンダー等の iCal URL
  • スケジュール編集 – 各時間帯の表示内容をカスタマイズ（折りたたみ式）

スケジュール編集

各時間帯（モード）ごとに以下を設定します。

  • 名称
  • 対象曜日
  • 開始時刻 / 終了時刻
  • 表示時間（秒）
  • 表示種別（固定カード または 写真＋インフォメーションカード）

「写真＋インフォメーションカード」を選ぶと、写真の合間に天気やカレンダー等の情報カードが約10分間表示されます。不要なモードは削除、新しいモードは追加可能です。

割り込み通知

  • カレンダー通知 – 予定の15分前に自動で通知カードを表示
  • 天気警報通知 – 気象警報発表時に自動表示

どちらも初期状態で有効です。設定画面の「Daily Schedule」セクション内で無効化できます。

5-6. 写真のみモードの動作

「写真のみ」モードでは写真のみを表示し、情報カードは表示されません。情報カードも交えたい場合はスケジュールモードで「写真＋インフォメーションカード」の時間帯を設定してください。

6. 全機能紹介

各機能はスケジュールに従って自動表示されます。

  • モーニングブリーフィング – 朝の挨拶、今日の天気と予定、季節の写真と時候の言葉
  • 天気 – 現在の気温、天気概況、湿度
  • 時計 – 4種のデザインから選択可能
  • カレンダー – 月/週/日表示。連携したカレンダー情報を表示
  • 写真 – アップロードした写真または Unsplash の写真を表示
  • ペインティング – 季節に合わせた名画を表示
  • イブニングカード – 明日の天気と予定、「お疲れさま」のメッセージ
  • グッドナイトカード – 月や星空の写真と静かなメッセージ
  • ミール＆ボキャブラリー – 日葡の食事単語と料理写真
  • ムードカード – 季節の花写真と日英バイリンガルメッセージ
  • Wikipedia 今日の一枚 – Wikipedia の注目画像
  • 今年の進捗 – 年の経過を視覚表示
  • 関西イベント情報 – 季節のスポットや催し
  • TODO リスト – 登録したタスクを表示
  • カウントダウン – 記念日までの残り日数
  • RSS – 指定フィードの最新見出し
  • AI テキスト（OpenAI API 要）– キーワードから文章生成
  • AI 画像（OpenAI API 要）– キーワードから画像生成
  • 天文写真（NASA API 要）– NASA の今日の天文写真
  • Unsplash（Access Key 要）– 高品質写真をランダム表示

8. 写真の活用

アップロード方法

  1. Web アプリの「写真」ページを開く
  2. アップロードボタンから画像を選択
  3. 自動でアップロード完了

写真はぼかし背景付きで自動レイアウトされて表示されます。

表示設定

設定ページで以下を変更できます。

  • 写真の切り替え間隔（分または時間単位）
  • 画像の鮮やかさ、明るさ、シャープネス、コントラスト

9. 便利な機能

Google カレンダー連携

  1. Google カレンダーの設定から「カレンダーの統合」の iCal URL をコピー
  2. 設定ページの「カレンダーURL」に貼り付け
  3. 保存

朝のブリーフィングやイブニングカードに予定が表示されます。予定の15分前には通知カードが自動表示されます。

天気設定

設定ページで緯度・経度を設定すると、その地域の天気が表示されます。気象警報が発表された場合は自動で通知カードが表示されます。

API キー設定

機能 必要なキー 取得先
AI テキスト/画像生成 OpenAI API Key platform.openai.com
Unsplash 写真 Unsplash Access Key unsplash.com/developers
NASA 天文写真 NASA API Key api.nasa.gov
天気警報 OpenWeatherMap API Key openweathermap.org

10. 困ったときは

画面に何も表示されない

  1. 電源ケーブルが本体とコンセントの両方に接続されているか確認
  2. 電源 LED が消灯している場合は電源ボタンを押す
  3. 10分以上変わらない場合は電源ボタンを5秒長押しして再起動
  4. それでも表示されない場合はケーブルを抜き30秒待って再接続

表示が更新されない

  1. 本体が Wi-Fi に接続されているか確認
  2. ルーターを再起動
  3. Web アプリにアクセスできるか確認

Web アプリにアクセスできない

  1. スマートフォン/パソコンが本体と同じ Wi-Fi に接続されているか確認
  2. URL が正しいか確認（http://inkypi.local/）
  3. ルーターの管理画面から本体の IP アドレスを確認し直接入力

時計や天気が正しくない

  1. 設定ページでタイムゾーンが「東京/日本」になっているか確認
  2. 天気の緯度・経度が正しいか確認

カレンダーが反映されない

  1. URL が正しいか確認（Google カレンダーの公開 iCal URL であること）
  2. webcal:// で始まる URL は自動変換されます
  3. 設定後、最大5分程度かかることがあります

本体が熱くなる / 動作が不安定

  • 風通しの良い場所に設置
  • 直射日光を避ける
  • ほこりの多い場所を避ける
